The simple explanation

One game, seven build tasks, three workers.

01

Fingerprint the inputs

ForgeGrid hashes the selected world, weapon, enemy rules, and dependency outputs.

02

Schedule only missing work

Available workers compile scripts and shaders, process textures and audio, then package the level and navigation concurrently.

03

Play the verified artifact

The final bundle carries checksums for every input that created the playable game.
